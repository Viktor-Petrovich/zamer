ПЛАТНАЯ ПРОБНАЯ ВЕРСИЯ (доступ по заявке и лимит замеров). Включается только при заполненном config.js.

ДОСТУП К ПРИЛОЖЕНИЮ ПО ЗАЯВКЕ И УЧЁТ ЗАМЕРОВ

КАК ЭТО РАБОТАЕТ
- Сотрудники, которых вы добавили в бота командой /adduser, и вы сами (администратор) входят в приложение сразу.
- Новый человек нажимает «Войти через Telegram» в приложении, в боте нажимает «Запустить». Вам приходит сообщение «Запрос доступа к приложению» с кнопками «Разрешить» и «Отклонить».
- После «Разрешить» человеку приходит сообщение, он нажимает «Войти через Telegram» ещё раз и работает. Ему сразу начисляется 10 демо-замеров.
- У администратора замеры без ограничений.
- Один замер списывается, когда заявка отправляется или скачивается. Повторная отправка той же заявки не списывает.
- Телефон заранее берёт у сервера до 3 замеров, поэтому без сети можно сделать до 3 заявок.
- Когда замеры закончились, приложение показывает номер пользователя и ваш контакт. Заявка сохраняется, после пополнения её можно отправить.

КОМАНДЫ АДМИНИСТРАТОРА (ваш id должен быть в TG_ADMIN_IDS в файле .env)
/apps                      кто имеет доступ, кто ждёт решения, остатки
/appallow 123456789        открыть доступ по номеру
/appdeny 123456789         закрыть доступ (человек сразу выйдет из приложения)
/addcredits 123456789 50   начислить 50 замеров
/credits                   остатки и выполненные замеры у всех
/balance                   свой остаток (доступна всем)
Количество демо-замеров меняется строкой DEMO_CREDITS=10 в файле .env.

ШАГ 1. ОБНОВИТЬ БОТА
1. Распакуйте архив maxbot_tg.zip поверх старой папки (согласитесь на замену). Файл .env не трогайте.
2. Закройте чёрное окно бота и запустите заново: python bot_tg.py
3. В окне должна быть строка «API учёта замеров: порт 8080».

ШАГ 2. ОТКРЫТЬ БОТА ДЛЯ ПРИЛОЖЕНИЯ ЧЕРЕЗ ИНТЕРНЕТ (ngrok)
Приложение живёт в интернете, а бот на вашем компьютере. ngrok соединяет их.
1. Зарегистрируйтесь на https://ngrok.com (бесплатно) и скачайте программу для Windows.
2. В кабинете ngrok откройте Domains и создайте бесплатный домен вида слово-слово.ngrok-free.app. Он не меняется.
3. Откройте второе чёрное окно и один раз выполните: ngrok config add-authtoken ВАШ_ТОКЕН (токен в кабинете, раздел Your Authtoken).
4. Запустите: ngrok http --url=ВАШ-ДОМЕН.ngrok-free.app 8080
5. Оба чёрных окна и компьютер должны оставаться включёнными, иначе вход в приложение не работает.

ШАГ 3. ВКЛЮЧИТЬ ПРОВЕРКУ ДОСТУПА В ПРИЛОЖЕНИИ
1. Откройте файл config.js (в папке приложения) и заполните:
   api: "https://ВАШ-ДОМЕН.ngrok-free.app"
   bot: "имя_вашего_бота"  (без @)
   contact: "@ваш_ник или телефон"
2. Загрузите config.js на GitHub: репозиторий zamer → Add file → Upload files → config.js (старый заменится) → Commit changes. Остальные новые файлы (app.js, pdf.js, index.html, sw.js) загрузите с заменой.
3. Через 1–2 минуты откройте приложение на телефоне, в меню нажмите «Обновить приложение». Должна появиться кнопка «Войти через Telegram».

ШАГ 4. ПРОВЕРКА
1. Войдите сами (вы администратор): должно появиться «Вход выполнен».
2. Попросите знакомого, которого нет в списке, нажать «Войти». Вам придёт запрос с кнопками. Нажмите «Разрешить» и проверьте, что он вошёл.
3. Команда /apps покажет список.

ЕСЛИ НЕ ВХОДИТ
Проверьте, что оба чёрных окна открыты, что адрес в config.js совпадает с доменом ngrok и что имя бота введено без @.
Чтобы вернуть приложение в открытый режим без входа, оставьте в config.js пустые кавычки: window.ZAMER = { api: "", bot: "", contact: "" };

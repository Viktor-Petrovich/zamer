УЧЁТ ЗАМЕРОВ В ПРИЛОЖЕНИИ (демо 10 замеров + пополнение вручную)

Как это работает
- Замерщик входит в приложение через Telegram (кнопка «Войти», в боте нажать «Запустить»).
- Новому пользователю даётся 10 бесплатных замеров.
- Один замер списывается, когда заявка отправляется или скачивается. Повторная отправка той же заявки не списывает.
- Телефон заранее берёт у сервера до 3 замеров, поэтому без сети можно сделать до 3 заявок.
- Когда замеры закончились, приложение показывает номер пользователя и просит написать администратору.

Команды администратора в боте (ваш id должен быть в TG_ADMIN_IDS)
/addcredits 123456789 50   начислить 50 замеров пользователю с номером 123456789
/credits                   остатки и количество выполненных замеров у всех
/balance                   свой остаток (доступна всем)

ШАГ 1. Обновить бота
1. Распакуйте архив поверх старой папки maxbot_tg (согласитесь на замену файлов). Файл .env не трогайте.
2. Остановите бота (закройте чёрное окно) и запустите заново: python bot_tg.py
3. В окне должна быть строка «API учёта замеров: порт 8080».

ШАГ 2. Открыть бота для приложения через интернет (ngrok)
Приложение живёт в интернете, а бот на вашем компьютере. ngrok соединяет их.
1. Зарегистрируйтесь на https://ngrok.com (бесплатно) и скачайте программу для Windows.
2. В личном кабинете ngrok откройте Domains и создайте бесплатный домен. Он выглядит как слово-слово.ngrok-free.app и не меняется.
3. Откройте второе чёрное окно и выполните (один раз): ngrok config add-authtoken ВАШ_ТОКЕН (токен виден в кабинете ngrok, раздел Your Authtoken).
4. Запустите: ngrok http --url=ВАШ-ДОМЕН.ngrok-free.app 8080
5. Оставьте оба окна открытыми. Компьютер должен быть включён, иначе приложение не сможет входить и списывать замеры.

ШАГ 3. Прописать адрес в приложении
1. Откройте файл config.js в папке приложения и заполните три строки:
   api: "https://ВАШ-ДОМЕН.ngrok-free.app"
   bot: "имя_вашего_бота"  (без @)
   contact: "@ваш_ник или телефон"
2. Загрузите config.js на GitHub: репозиторий zamer → Add file → Upload files → файл config.js (старый заменится) → Commit changes. Остальные новые файлы приложения (app.js, index.html, sw.js) тоже загрузите с заменой.
3. Через 1–2 минуты откройте приложение на телефоне, закройте и откройте ещё раз. Должна появиться кнопка «Войти через Telegram».

ШАГ 4. Проверка
1. Нажмите «Войти через Telegram», в Telegram нажмите «Запустить», вернитесь в приложение.
2. На главном экране должно быть «Осталось замеров: 10».
3. Пройдите заявку и нажмите «Скачать PDF». В боте команда /credits покажет, что выполнен 1 замер.

Если приложение не входит: проверьте, что оба чёрных окна открыты, что адрес в config.js совпадает с доменом ngrok и что имя бота введено без @.
Если APK уже собран через pwabuilder, пересобирать его не нужно: он открывает ту же страницу, и обновления приходят сами.

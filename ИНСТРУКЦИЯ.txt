ПРИЛОЖЕНИЕ «ЗАМЕР ОБРАМЛЕНИЙ ДШ» — установка

ЧАСТЬ 1. Выложить приложение в интернет (бесплатно, 5 минут)
1. Зайдите на https://github.com и создайте аккаунт (или войдите).
2. Нажмите «+» вверху справа → New repository. Имя: zamer. Поставьте Public. Нажмите Create repository.
3. На странице репозитория нажмите «uploading an existing file».
4. Распакуйте zip на компьютере. Перетащите в окно браузера ВСЁ содержимое папки (index.html, app.js, pdf.js, sw.js, manifest.webmanifest, иконки). Нажмите Commit changes.
5. Откройте Settings → Pages. В Source выберите «Deploy from a branch», Branch: main, папка / (root). Нажмите Save.
6. Через 1–2 минуты вверху появится адрес вида https://ВАШ-ЛОГИН.github.io/zamer/ — это ссылка на приложение.

ЧАСТЬ 2А. Установка без APK (самый быстрый путь)
1. Откройте ссылку в Chrome на Android.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Значок «Замер ДШ» появится на экране. Откройте один раз при наличии интернета — дальше работает без сети.

ЧАСТЬ 2Б. Получить настоящий APK-файл
1. Откройте https://www.pwabuilder.com, вставьте адрес из части 1, нажмите Start.
2. Дождитесь проверки, нажмите Package for stores → Android → Generate Package.
3. В поле Package ID оставьте предложенное (например, io.github.логин.zamer), остальное по умолчанию. Нажмите Download.
4. Из скачанного архива возьмите файл с расширением .apk (например, app-release-signed.apk). Файлы signing.keystore и пароль сохраните: они нужны для обновлений.
5. Передайте APK на телефон (мессенджер, почта, USB).
6. На телефоне откройте APK. Android попросит разрешить установку из этого источника — разрешите. Нажмите «Установить».

ЧАСТЬ 3. Работа
- Заполните вопросы, на последнем экране нажмите «Отправить в снабжение» — откроется список приложений (Telegram, Max, почта), выберите чат снабжения. PDF называется адресом объекта.
- Если список не открылся, файл сохранится в «Загрузки» — отправьте его оттуда.
- Обновление приложения: загрузите новые файлы в тот же репозиторий, при следующем запуске с интернетом оно обновится.
